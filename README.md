## 📖 About

MiniBot is a premium voice-activated AI assistant for Android that combines cutting-edge artificial intelligence, intuitive voice interaction, and stunning 3D visual design. Built from scratch in Android Studio using Java, MiniBot features a mesmerizing black hole animation background, over 50 voice commands, AI-powered conversations, and comprehensive device control.

---

## ✨ Features

### 🎤 Voice & AI
- **Wake Word**: "Hey MiniBot" activation
- **AI Chat**: Powered by Google Gemini 2.0 Flash
- **Speech Recognition**: Real-time voice-to-text
- **Dual TTS**: ElevenLabs premium + Android built-in

### 🌌 Visual Experience
- 3D animated black hole with 3000 particles
- Rotating accretion disk and starfield
- Glass-morphism dark sci-fi UI
- Animated splash screen with creator branding

### 📱 App Control
Open 15+ apps via voice: YouTube, Chrome, Instagram, WhatsApp, Spotify, Facebook, Twitter, Camera, Calculator, Maps, Gmail, Play Store, Gallery, Calendar, Clock

### 📞 Communication
- Make phone calls
- Send SMS messages

### ⏰ Utilities
- Set alarms & timers
- Create reminders & calendar events
- Weather & news updates
- Google & YouTube search
- Calculator & conversions

### 📊 System
- Live CPU, RAM, Network monitoring
- Battery status
- Device information
- WiFi/Bluetooth shortcuts

### 😂 Entertainment
- Random jokes & quotes
- Fun facts
- Engaging personality

 Tech Stack

| Category | Technology |
|----------|------------|
| **Language** | Java (Android Native) |
| **UI** | XML, Material Design |
| **3D Graphics** | Three.js via WebView |
| **AI Brain** | Google Gemini 2.0 Flash API |
| **Voice Output** | ElevenLabs API + Android TTS |
| **Voice Input** | Android SpeechRecognizer |
| **Search** | Serper.dev Google Search API |
| **Networking** | OkHttp |
| **Data Parsing** | JSON (org.json) |
| **Security** | EncryptedSharedPreferences (AES-256) |
| **Build** | Gradle 9.4.1, AGP 8.9.1, JDK 17 |
